# 🚀 ML_Pipeline_API

A machine learning project that predicts whether a telecom customer is likely to churn, so a retention team can contact at-risk customers early. Customer data is stored in SQLite, processed with a scikit-learn pipeline, and served through a FastAPI endpoint.

## Goal

Predict whether a telecom customer will churn, using data stored in SQLite, and serve the prediction through a FastAPI endpoint.

## Dataset 

- Telco Customer Churn (IBM sample, from Kaggle)
